# Memberships have an explicit end, and nothing rolls over

Every membership has a start semester and an end semester. By default the end is two semesters after the start, and a team can set one semester instead. Whether a membership is active is calculated from the current semester. To stay longer, a team leader extends the membership. Promotion, demotion and moving to another team end the old membership and start a new one. A placement always lasts one semester.

In the 2024 backup, 103 of 780 memberships had no end semester, many of them started between 2016 and 2021. 676 were flagged suspended by a job that ended memberships. Open-ended memberships go stale, and stale memberships keep their access. The most common length of a finished membership is two semesters (317 of 677).

## Considered options

- **Automatic rollover each semester, with explicit exit.** Rejected: a person who forgets to leave keeps access.
- **Suspension flag set by a job.** Rejected: it is a second state that can disagree with the dates, as it did in the legacy system.

## Consequences

- A team leader must extend memberships each semester. An "ending soon" list four weeks before the semester ends makes this a one-click task.
- If all leader memberships in a department end at the same time, the board and the admins can still add members.
